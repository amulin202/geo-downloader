# GeoD 智能解析 Google URL 子域名修复

用户示例：`https://mt{s}.google.com/vt/lyrs=m&hl=en&x={x}&y={y}&z={z}`。

当前解析器已经保留固定参数 `hl=en`、`lyrs=m`，但把 `{s}` 一律替换为 `a`，生成 `mta.google.com`；返回值的 `subdomains` 为空，保存自定义图源后下载器不会替换 `{s}`。已确认这两个代码缺陷，无法仅凭历史截图认定用户当时版本的全部故障原因。

修复：按完整主机模板匹配内置图源，复用其子域名配置；样例请求和返回的自定义图源字段使用同一份配置。Google 回填 `0,1,2,3`；普通未知模板采用 `a,b,c` 供用户调整，没有 `{s}` 时保持为空。保留固定参数及编码后的 Token 内容。

验证：新增三个回归测试，覆盖截图中的路径形式、普通查询形式、编码参数、具体坐标解析、自定义未知域名和相似域名隔离，以及从解析结果到真实下载器的 URL 构造。`cargo test --lib` 共 155 项通过。

通过本机代理请求 `https://mt0.google.com/vt/lyrs=m&hl=en&x=1&y=1&z=1`，返回 HTTP 200、`image/png`、3,919 字节，解码为 256 × 256 PNG。此验证为单张瓦片，不是整批下载结果，不保证用户网络环境可用。

修复位于 `codex/geod-overlay-memory`，尚未发布新版。现版用户可在自定义图源中手动填写子域名 `0,1,2,3`，或用 `mt0.google.com` 代替 `mt{s}.google.com`。
