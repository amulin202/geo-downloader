# v3.6.13 — 原始瓦片边界裁剪与大任务内存修复

- 原始瓦片目录新增“按边界裁剪”，支持矩形、多边形、多区域和多级别下载。
- 裁剪后统一输出 PNG，保留原瓦片尺寸及 `z/x/y` 编号；边界外像素透明，整张在界外的瓦片不导出。
- 注记先叠加再裁剪，保持图层顺序和透明度；关闭裁剪时继续保留原始瓦片格式。
- 修复大任务、多层注记下载时缓存瓦片与合成 PNG 整批常驻内存的问题，改为逐张落盘、按文件路径导出。
- 合成及裁剪过程新增计数进度，支持暂停和取消；保留原始输入供中断后恢复，避免重复叠加。
- 修正原始瓦片、MBTiles、GeoPackage 的内存预估，使用逐瓦片工作集而非整幅画布估计；预警仍仅提示，可自定义或不限。
- 修复智能解析 Google `mt{s}` URL 时错误使用字母子域名、保存时漏填子域名的问题。固定参数（如 `hl=en`）与占位符可以同时保留，样例测试和下载统一使用 `mt0`～`mt3`。

裁剪 PNG 可能比原始 JPG 更占磁盘；逐张落盘会增加磁盘读写。下载仍需足够磁盘空间和可用网络，并受图源服务能力约束。
