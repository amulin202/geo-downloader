# v3.6.11 — 消息通知与下载稳定性

这次为经典 GeoD 桌面版整理了 3.6.10 之后的下载、图源和缓存改进，并加入与 GeoD Agent 相同类型的消息中心。

## 消息中心

- 顶部新增铃铛入口，未读消息显示红色角标。
- 支持产品更新、服务公告、指定账号通知，以及重要消息提醒。
- 可查看全部或仅未读消息，展开后标记已读，也可一键全部已读。
- 消息列表有最大高度，长内容在面板内滚动；支持中英文与深浅色外观。
- 可在系统浏览器连接 GeoD 账号，同步不同设备的已读记录。下载功能不要求登录。
- GeoD 与 GeoD Agent 的公告受众、登录凭据和权限分别处理。GeoD 通知登录只申请通知权限，不调用模型、不领取 Agent 体验额度、不消耗 Credits。
- 离线时保留当前账号上次保存的消息；退出或切换账号后不显示其他账号的缓存。
- 通知内可提供更新检查或 HTTPS 链接；服务器仍负责限制账号、版本、发布时间和有效期。

## 下载与图源

- 修改自定义图源后立即保存，删除图源前要求确认。
- 对瓦片响应进行格式检查，避免把错误页面或无效数据写成影像成果。
- 遇到鉴权失败时停止无效重试；遇到限流时按照等待提示进行有界重试，等待可取消。
- 补强暂停、恢复和缓存协调，减少继续下载时的状态冲突。
- 瓦片合并按实际瓦片尺寸处理，覆盖 512 像素瓦片场景。
- OpenStreetMap 公共标准瓦片服务的离线下载限制同时覆盖内置图源、自定义地址和叠加图层；仍可正常在线浏览或换用允许离线下载的服务。

## 可选匿名统计

- 用户同意后记录下载开始、完成、缺块完成、失败、取消、耗时区间及错误类别。
- 不采集任务名称、文件路径、下载地址、地图坐标、原始错误或下载数据。
- 统计范围变更需重新征求同意；已有历史任务不冒充新完成的下载。

## 升级说明

已有任务、输出文件、设置和缓存继续保留。通知账号属于可选连接，不替换原有下载流程。

消息中心需要配套通知服务支持 `geod` 产品和 `geod-desktop` 客户端。安装包发布前，应先完成服务端兼容更新和授权、收件箱、已读回执的线上验证。

当前验证范围为 Windows 本地构建和测试；macOS、Linux 的安装包与系统凭据行为需各平台构建及验证后再宣称支持。
