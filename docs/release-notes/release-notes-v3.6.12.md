# v3.6.12 — 自定义预警阈值与设置保存修复

- 内存估算超出预警阈值时只作提示，仍可下载并继续导出。
- 瓦片数量超过原 500,000 阈值时只作提示，不再禁止下载，覆盖多级别下载。
- 设置中可自定义内存和瓦片数量预警阈值，支持“不限”（0）；取消原 16 GB 内存设置上限。
- 修改预警设置后，下载估算随之刷新。
- 修复关闭 AI 功能时隐藏的 AI 配置校验阻止整页设置保存的问题。
- 天地图 Token 附近新增“保存设置”入口和未保存/已保存状态；保存后重新读取核对，失败时明确显示原因。
- 保存已有任务、缓存和其他设置，保留 3.6.11 的消息中心与蓝色 G 图标。

预警阈值仅控制提示，实际下载和导出仍受设备可用资源及图源服务能力约束。
